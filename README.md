# Gomoku Arena

一个可直接在浏览器运行的五子棋游戏，支持本地双人对战与人机对战。

## 功能

- 15 × 15 棋盘，黑方先行，横、竖、斜线连成五子获胜
- 本地双人模式
- 人机模式：简单、普通、困难三档难度
- 悔棋、重新开局、胜利连线提示
- 适配桌面和手机触屏，也可用方向键与回车键操作棋盘

## 本地运行

项目是纯静态网页。直接打开 `dist/index.html` 即可开始游戏；也可以在项目根目录启动任意静态文件服务器，并以 `dist` 为网站目录。

## 项目结构

```text
dist/
  index.html   页面结构
  styles.css   页面样式
  game.js      棋盘、规则与电脑对手
```

无需安装依赖。
